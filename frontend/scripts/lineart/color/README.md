# Colored character views

The four color illustrations align with the existing vector silhouettes. The generated masters contain an unwanted exterior halo: `FigureArtwork` clips the color layer to the outer contour of each existing vector path, excluding interior linework holes from the clip so the colored body stays filled. The front view adds a face contour because the open face area falls outside the traced ink contours. Do not render these masters or runtime images without the silhouette clip. The viewer embeds the optimized WebP layers inside its SVG so the artwork, camera and annotation anchors share one coordinate system. The home drawing remains vector line art.

- Editable generated masters: `front.png`, `left.png`, `back.png`, `right.png`.
- Runtime assets: `frontend/public/media/character/*-color.webp`, encoded with Sharp at quality 92 and alpha quality 100.
- Registration: image x = -312, y = -13.75, width = 1024, height = 1536. Do not crop the canvas without updating image registration and checking all trait anchors.
- Generated using the imagegen tool. These are colored raster illustrations, not vector-traced color fills.
